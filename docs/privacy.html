BUA — Browser Use Agent

隐私政策

最后更新：2026 年 10 月 12 日 · 适用产品：BUA Chrome 扩展

BUA 不收集、不存储、不上传你的任何数据。
扩展包内没有任何网络请求代码 —— 它只监听本机的 127.0.0.1 回环连接。

1我们收集什么

不收集任何数据。

BUA 扩展不联系服务器、不上传遥测、不接入任何分析服务、不加载任何远程资源。 它唯一打开的 socket 是到本机 127.0.0.1 的本地回环连接。

2扩展读取什么，以及为什么

为了让你的本地程序能够操作浏览器，扩展需要读取以下内容。这些内容 全部只在你的设备上、在内存中处理，用于执行你本机程序发出的指令。

内容何时读取用途是否离开设备
当前标签页的 URL 与标题你的程序请求时让程序知道当前在哪一页否
页面结构与可见文本（DOM）你的程序请求时执行你程序发出的读取指令否
页面截图你的程序请求时执行你程序发出的截图指令否
你打开的标签列表你的程序请求时让你选择把哪个标签交给程序操作否

读取范围：仅限你在引导页明确启用后、由你自己的本地程序主动请求的那些标签。 扩展不会在后台扫描你的浏览活动，也不会建立浏览历史记录。

3数据存放在哪里

全部存放在你的设备本地（Chrome 的 chrome.storage.local）：

数据内容保留
授权时间戳你确认风险告知的时间直到你卸载扩展
能力快照当前 CDP 是否可用直到你卸载扩展
操作流水最近 200 条操作记录（方法名、意图描述、结果）超出后自动丢弃，可一键清空

这些数据都不会离开你的设备。

4我们与第三方共享什么

不共享任何数据。因为扩展根本不向外发送数据。

5关于本地连接的重要说明

BUA 通过本地回环连接与本机程序通信。这个连接不校验调用方身份 —— 任何能访问本机 127.0.0.1 的程序都可以连接它并操作你的浏览器。

这是刻意的设计取舍：为了让你能自由选择任意工具，而不是被迫绑定某一个特定产品。

这意味着：

  • 本机上的其他程序（包括恶意软件）也能通过 BUA 操作你的浏览器
  • 不过本机恶意软件本来就拥有你的用户权限（可以读取 Chrome 的配置文件与 Cookie）， BUA 并没有赋予它新的能力上限 —— 但它确实降低了一个门槛

扩展首次启用时会完整告知这一风险，并且需要你主动勾选确认， 之后才会建立任何连接。

6页面内容可能间接流向 AI 服务

BUA 本身不会上传任何内容。但请注意：

如果你用 BUA 配合一个 AI agent（例如某个本地 agent 工具），那么该 agent 可能会把页面内容发送给它自己的模型服务商。那是那个 agent 的行为，不是 BUA 的行为， 并且受该 agent 自身的隐私政策约束。

BUA 的职责边界很清楚：它只把浏览器操作能力提供给本机程序，不参与、也不控制本机程序之后如何使用这些能力。

7我们不做的事

明确声明，以下行为 BUA 一律不做：

  • 不收集个人身份信息
  • 不收集健康信息
  • 不收集财务与支付信息
  • 不收集认证信息（账号密码、Cookie 值）
  • 不收集个人通信内容
  • 不收集位置信息
  • 不记录浏览历史
  • 不收集用户活动数据用于分析或画像
  • 不向第三方出售或转让任何用户数据
  • 不将用户数据用于与单一用途无关的目的
  • 不将用户数据用于判定信用状况或放贷用途

8儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童的任何信息。

9政策变更

若本政策有实质变更，我们会更新本文档顶部的日期，并在扩展的更新说明中告知。 由于本扩展不收集任何数据，预期不会出现需要用户重新同意的变更。

11如何自行验证本政策

我们鼓励你不信任任何隐私声明，而是自己验证：

  1. 打开 chrome://extensions，找到 BUA，点击「详情」
  2. 查看权限列表 —— 你会看到它没有申请任何网站访问权限（host permissions 为空）
  3. 在 chrome://extensions 打开开发者模式， 使用「检查视图 → service worker」打开扩展的后台调试器
  4. 切到 Network 标签 —— 你会看到没有任何网络请求
  5. 阅读源码：packages/extension/src/background.ts 中唯一的 socket 是 ws://127.0.0.1:17432
