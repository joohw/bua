ZIP 手动安装

适用于 Chrome 和 Edge。

下载 BUA 扩展 ZIP · v0.1.1

下载 SHA-256 校验文件

  1. 下载 ZIP 包并解压到一个固定文件夹。
  2. 在地址栏打开 chrome://extensions（Chrome）或 edge://extensions（Edge）。
  3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
