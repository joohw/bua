在 DeepSeek Harness 中使用 BUA 浏览器插件

dsh-plugin-bua 是 BUA 的 DeepSeek Harness 原生插件。安装后插件自动启动或复用本地桥，把浏览器能力注册为 bua_* 工具，DSH 中的 AI Agent 可以直接读取、截图和操作用户已登录的真实标签页（复用登录态与 Cookie），无需手动配置 MCP 或开放 CDP 端口。

安装插件 npm 包

安装 dsh-plugin-bua

在已安装 DeepSeek Harness 的机器上执行，把 demo 换成你要使用的 profile 名称：

dsh plugin --profile demo add dsh-plugin-bua
dsh --profile demo

插件会自动管理本地桥，不需要再手动运行 bua-server。但 BUA 浏览器扩展仍要独立安装，并在引导页阅读风险告知后主动启用。

从源码安装：pnpm --filter dsh-plugin-bua... run build 后执行 dsh plugin --profile demo add ./packages/dsh-bundle，再用 dsh --profile demo --dump-config 确认插件已加入 profile。

插件接入与 MCP 接入怎么选

DeepSeek Harness 优先用原生插件；只有其他 MCP 客户端才需要手动启动本地桥并配置 stdio 入口。

项目dsh-plugin-bua 原生插件stdio MCP
本地桥 插件自动启动或复用 需手动运行 @bua/server
客户端配置 dsh plugin add 一条命令 编辑客户端的 MCP 配置
工具呈现 bua_* 命名空间 客户端 MCP 工具列表
适用 DeepSeek Harness OpenClaw、Hermes Agent 等

Agent 可用的浏览器工具

插件注册的工具都以 bua_ 开头。建议先只读确认页面，再执行变更操作；变更类工具需要提供人类可读的 targetDescription。

类型工具用途
连接与只读 bua_browser_info、bua_tabs_list、bua_tab_info、bua_tab_dom_snapshot、bua_tab_text、bua_tab_screenshot 确认扩展后端、列出标签、读取标题网址、获取可交互元素、读取正文与截图。
页面操作 bua_tab_click、bua_tab_fill、bua_tab_type、bua_tab_click_at、bua_tab_navigate、bua_tab_open、bua_tab_close、bua_tab_evaluate 点击、填写、输入、导航、开关标签与执行页面 JS；均需说明操作目标与意图。

第一次验证：确认 DSH 已连上浏览器

  1. 向 Agent 发送：“使用 BUA 的 bua_browser_info 确认浏览器已连接，然后用 bua_tabs_list 列出标签。”
  2. bua_browser_info 返回 connected: true 且显示扩展后端，才说明浏览器链路可用；只看到工具列表不代表扩展已连上。
  3. 用 bua_tab_info 核对目标标签的标题和网址，再按需只读或操作。

安全边界

本地桥默认监听 127.0.0.1:17432，不做调用方身份认证：任何能访问本机回环地址的进程都可能操作浏览器，包括已登录页面。仅在本机使用，不要把桥暴露到公网；Harness 的工具策略负责确认与权限控制，targetDescription 本身不代表用户授权。

常见问题

dsh plugin 怎么安装 BUA 浏览器插件？

执行 dsh plugin --profile <profile> add dsh-plugin-bua，然后 dsh --profile <profile> 启动；插件会自动管理本地桥，BUA 浏览器扩展仍需单独安装并启用。

dsh-plugin-bua 和 MCP 接入有什么区别？

dsh-plugin-bua 是 DeepSeek Harness 的原生插件，会自动启动或复用本地桥，工具直接注册为 bua_*；MCP 接入需要手动启动本地桥，并在客户端配置 stdio 入口。其他 Harness 的 MCP 配置见接入指南。

安装 dsh-plugin-bua 后还需要安装 Chrome 扩展吗？

需要。插件只负责管理本地桥和暴露工具，BUA 浏览器扩展仍需独立安装、在引导页同意启用，并连接到本地桥。

为什么工具名是 bua_ 前缀？

插件把浏览器能力注册在 bua_ 命名空间下，避免与 Harness 中的其他工具重名，例如 bua_browser_info、bua_tabs_list、bua_tab_click。

在 DeepSeek Harness 中如何验证 BUA 已连接？

让 Agent 调用 bua_browser_info，返回 connected: true 且显示扩展后端才表示链路可用；随后用 bua_tabs_list 列出标签，再用 bua_tab_info 核对标题和网址。
