## 名称

```
BUA — Browser Use Agent
```

（manifest 里就是这个名字，Dashboard 必须一致）

## 简短描述（不超过 132 字符）

```
让本地程序与 AI agent 操作你已登录的真实浏览器。无需重新登录，无需重启浏览器。
```

字符数：**41**（上限 132，余量充足）

英文版：

```
Let local tools and AI agents drive your own signed-in browser. No re-login, no browser restart.
```
字符数：**95**

## 详细描述

```
BUA 把你的浏览器变成一个可编程的操作对象 —— 让本地程序或 AI agent 在你**已经登录**的
浏览器里读取页面、点击、输入、截图。

■ 为什么需要它

现有的浏览器自动化方案各有硬伤：
• 独立浏览器（Playwright / Puppeteer）：没有你的登录态，要重新登录、过风控、扫验证码
• 直连调试端口：CDP 端口无认证，本机任意进程连上就能完全控制浏览器；而且 Chrome 136+ 已
  对默认配置文件静默禁用该端口
• 云浏览器：你的登录信息与页面内容要离开本机

BUA 走另一条路：它作为浏览器扩展，从**浏览器内部**获取操作能力。因此它能操作你真实的
标签页、使用你真实的登录态，**不需要重启浏览器，也不开放任何调试端口**。

■ 你会看到什么

• 被操作的标签页四周会出现一圈**边缘泛光** —— 蓝色表示正在操作，琥珀色表示已降级
• Chrome 顶部会显示它自己的调试横幅。这是 Chrome 的行为，无法隐藏；**关掉它就会立即
  终止本次会话**，你随时可以这样做
• 点击扩展图标可以看到完整的操作流水：谁在操作、做了什么、操作意图是什么

■ 权限说明

本扩展需要 debugger 权限，因为它要提供三项 chrome.scripting 做不到的能力：
真实输入事件、页面截图、跨 iframe 的一致控制。

本扩展**不申请任何网站访问权限**（host permissions 为空）—— debugger 本身已包含所需能力。

■ 隐私

• 本扩展**没有任何网络代码**，不联系任何服务器
• 页面内容仅在设备内存中处理，用于执行你本机的程序所发出的指令
• 不记录、不存储、不上传你的浏览历史或页面内容
• 所有数据都在你的设备上

■ 风险告知（重要）

BUA **不校验调用方的身份**：任何能访问本机 127.0.0.1 的程序都可以连接它并操作你的浏览器。
这是刻意的设计取舍 —— 为了让你能自由选择任意工具，而不是被迫绑定某一个。

如果你需要隔离，请勿启用，或只在专用机器 / 专用浏览器配置文件上使用。

首次启用时扩展会显示完整的风险说明，需要你主动确认。

■ 开源

MIT 许可。源码：https://github.com/joohw/bua

自由、开源，欢迎审计。
```

## 图标与截图

| 素材 | 要求 | 状态 |
|---|---|---|
| 商店图标 | 128×128 PNG | ✅ 随包提供 `icons/icon-128.png` |
| 截图 | 至少 1 张，1280×800 或 640×400 | ⬜ **需人工截取**（见下） |
| 小型宣传图 | 440×280（可选） | ⬜ 可选 |

### 需要人工准备的截图

用真实运行状态截图，不要用设计稿 —— 审核员会与实际行为对照。建议三张：

1. **引导页**（风险告知 + 同意勾选框）—— 证明显著披露确实存在于扩展 UI 内
2. **泛光 + 弹窗** —— 一个标签正在被操作（蓝色泛光），同时弹出操作流水
3. **降级状态**（可选）—— 琥珀色泛光 + 警示行

项目里已有可参考的渲染图：

- `docs/images/edge-glow-active.png`
- `docs/images/edge-glow-degraded.png`
- `docs/images/e2e-real-glow.png`（真实 Chrome 里由真实扩展注入的泛光）

> ⚠️ 泛光截图是在 `data:` 页面上取的。商店截图建议用**真实网站**，更贴近用户预期。
